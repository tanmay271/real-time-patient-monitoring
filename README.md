# Real-Time Patient Vital Signs Monitoring

A serverless AWS application that ingests a continuous stream of synthetic
patient vital-sign readings, evaluates each reading against configurable
thresholds, raises and tracks alerts through an acknowledgement and resolution
lifecycle, and displays live patient state on an authenticated web dashboard.

MSML 650 Cloud Computing term project · University of Maryland · Fall 2026

> **This is an educational prototype, not a medical device.** All patient
> identifiers and readings are synthetic and generated by the simulator in this
> repository. No real patient data is used at any point. All alert thresholds are
> project settings chosen for demonstration and are not medical guidance.

## Quick start

Requirements: Python 3.13, Node 20, AWS SAM CLI, AWS credentials for the project
account.

```bash
git clone <repo-url> && cd real-time-patient-monitoring
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
```

**Run the simulator locally, no AWS needed:**

```bash
python simulator/simulator.py --scenario normal --iterations 2
```

**Deploy your own stack:**

```bash
cd infra
sam deploy --stack-name patient-monitoring-<yourname> \
           --parameter-overrides Env=<yourname> \
           --capabilities CAPABILITY_IAM
```

**Send readings to it:**

```bash
python simulator/simulator.py --scenario falling_oxygen \
                              --iterations 10 \
                              --api-url "$API_URL"
```

**Run the dashboard:**

```bash
cd frontend && npm ci && npm run dev
```

**Tear down:**

```bash
sam delete --stack-name patient-monitoring-<yourname>
```
